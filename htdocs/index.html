What we do

MNK Solutions LLC is an independent software studio based in Oregon. We design and develop applications for sports coaching and team management, with an emphasis on simplicity, privacy, and offline-first reliability.

Supertrainer is a tablet application for managing drills, tracking player wellness, and recording injury reports — built for the sideline, not the server room.

Turf Wire is a free agent marketplace for indoor soccer. Managers post an open spot when they're short a player, free agents claim it, and the game happens — no spreadsheet, no forty text messages.
